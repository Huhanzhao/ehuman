# eHuman

#### 介绍
基于 Spring AI Graph 框架的拟人 AI 项目。支持按节点自由搭配不同模型与 API Key，具备语音合成、图片识别、向量检索、主动消息等能力，让 AI 成为你想要的任何角色。

#### 软件架构
- 语言：Java
- 工作流：Spring AI Graph
- 存储：SQLite
- 检索：本地向量库

#### 安装教程
- **方式一（推荐）**：Windows 一键安装，下载对应版本 exe多个压缩包，放到本地同一个目录下使用7zip等解压软件解压第一个压缩包得到完整exe文件，双击运行即可。
- **方式二**：本地运行或使用 Docker 镜像 `huhanzhao0355/human`。

#### 使用说明
安装成功后，进入安装目录下的app目录下，双击启动.bat 根据引导等待启动即可
连通qq后，输入 `#` 号，根据提示配置相关信息即可开始使用。
