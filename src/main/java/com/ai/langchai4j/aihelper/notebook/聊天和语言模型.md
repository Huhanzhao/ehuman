# 聊天和语言模型
## 1.1大模型的创建
引入maven坐标 直接autoware注入

<dependency>
<groupId>dev.langchain4j</groupId>
<artifactId>langchain4j-open-ai-spring-boot-starter</artifactId>
<version>${langchain4j.version}</version>
</dependency>

## 1.2 调用方法 chat()
传入String-> String
传入Message -> chatResponse 可以是多个message 或 List
使用request可以调试温度 绑定工具等
