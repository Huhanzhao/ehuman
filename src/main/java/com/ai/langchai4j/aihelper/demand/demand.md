# 2.整体需求
## 2.1 基础需求：
* ai对话：长久记忆功能，rag检索资料库 根据描述生成图片 图片提取文字 
* 登录、注册功能（邮箱验证或其他免费验证方式）、人机校验功能（可选）
* 角色权限管理功能,用户档案管理（增删查改 大文本 支持RAG检索）
* 创建知识库，支持上传文件，删除文件，查看文件列表，文件下载，模糊搜索


## 2.2 增强需求：
* 用户可以主动选择ai回答的时候关联哪些文件
* 统计分析 管理员可以查看用户数 文件数量 RAG调用量 生成图片的次数
* 日志和监控模块：用户操作日志（如上传文件、生成图片、登录尝试）  
* AI 请求日志（RAG 检索耗时、调用接口统计） 系统监控（CPU、内存、请求统计） 可以用 Spring Boot Actuator + ELK + Grafana 展示监控能力。
